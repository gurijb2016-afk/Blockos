# Pinned versions for the GNOME 42 target

| Component | Version | Official source |
|---|---:|---|
| GLib / GObject / GIO | 2.72.4 | https://download.gnome.org/sources/glib/2.72/glib-2.72.4.tar.xz |
| libffi | 3.4.2 | https://github.com/libffi/libffi/releases/tag/v3.4.2 |
| Cairo | 1.16.0 | https://cairographics.org/releases/cairo-1.16.0.tar.xz |

GLib 2.72.4 is the 2.72 final release used by GNOME 42.x. Cairo 1.16.0 is a
stable Cairo release used by the GNOME 42 era stack. libffi 3.4.2 is pinned
here for a conservative GNOME 42-era ABI baseline.
